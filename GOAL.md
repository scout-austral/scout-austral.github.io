# Competencia "Tu tiempo, tu Mundial"

## Objetivo

Desarrollar un sistema que analice el perfil de un usuario (horarios disponibles, equipos, jugadores favoritos u otras variables) para recomendar qué partidos de la primera fase del Mundial 2026 debería ver.

El sistema clasifica los partidos en tres categorías:

- **Imperdible:** Partidos indispensables por relevancia y afinidad.
- **Vale la pena:** Partidos interesantes pero no cruciales, o en horarios complejos.
- **Para ver el resumen:** Partidos de bajo interés para el perfil o en horarios imposibles.

## Entregables

1. **Demo interactiva** — Aplicación web pública (GitHub Pages) que permita configurar un perfil de usuario, visualizar recomendaciones de partidos y, idealmente, justificar la clasificación realizada.
2. **Informe metodológico** — Documento PDF (máximo 8 páginas) con resumen ejecutivo, explicación de variables, arquitectura del modelo y metodología de validación.
3. **Repositorio de código** — Repositorio público en GitHub con código fuente completo, datos utilizados e instrucciones de ejecución.

## Criterios de evaluación

- **Creatividad analítica:** Identificación y cuantificación de factores no evidentes que determinan el interés de un partido, más allá de métricas tradicionales como el ranking FIFA.
- **Rigor metodológico:** Solidez en la justificación de las recomendaciones y la métrica de éxito elegida para validar el modelo.
- **Demo interactiva:** Funcionamiento correcto de punta a punta y experiencia de uso clara e intuitiva para cualquier usuario.
